-----------------------------------------
Input: GET request to http://127.0.0.1:8000/
Expected Output: 
- Status Code: 200

Test Scenario 3: Navigate to Contact Webpage
--------------------------------------------
Input: GET request to http://127.0.0.1:8000/contact/
Expected Output:
- Status Code: 200

- CSRF token present

Test Scenario 4: Partial Form Submission (Validation Error)
----------------------------------------------------------
Input: POST to http://127.0.0.1:8000/contact/
Form Data:
- name: "John" 
- email: "invalid-email"
- phone: "123"
- message: ""

Expected Output:
- Status Code: 200 (form redisplays with errors)
- Email validation error displayed
- Phone validation error (too short)
- Message required field error
- Form retains valid data (name)
